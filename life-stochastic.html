Stochastic Life on a Torus

Conway's Life with probabilistic birth/survival, drawn on a 3D torus. Each generation a cell's fate is a coin-flip: count its 8 neighbours, look up the probability for that count, roll. The grid's edges are glued, so patterns leaving one side return on the other.

Rule + σ (the stochastic part)

The B/S rule no longer decides outright — it sets the neighbour counts where each probability peaks. The Create and Survive curves are shaped independently, each with three knobs: σ (width — σ→0 recovers the hard deterministic rule, larger is fuzzier), ceiling (max probability at the peak — <1 adds mortality even in ideal conditions), and floor (min probability everywhere — >0 adds spontaneous birth/death). The graph plots both live: amber = create, cyan = survive, dashed = each curve's floor/ceiling.

Because the rule is random, configurations essentially never repeat — so there is no stable/loop detection here (it lives in the deterministic version).

Topology

  • Torus — both edge pairs wrap.
  • Klein bottle — one seam flips; patterns return mirrored.
  • Möbius / Cylinder — one edge pair is open; cells die at that boundary.

Tools (act on the surface)

  • Orbit — left-drag rotate, right-drag pan, wheel zoom.
  • Pen — left-drag paints cells (first cell sets draw vs erase); right-drag still pans.
  • Glider — left-click drops a glider (it will dissolve under noise — that's expected).

Run & shape

  • Play / Step — run continuously, or one generation.
  • Random / Clear — seed by density, or empty the grid.
  • Speed, Density, Grid size — sliders; Apply size rebuilds the grid.
  • 2D / 3D view — flat grid (seam behaviour visible) vs torus; Reset view re-centres.
