Life on a Torus

Conway's Game of Life on a wrap-around grid, drawn on a 3D torus. Each generation, cells live or die by their 8 neighbours (with several bacteria types, by a signed count — see Bacteria). The grid's edges are glued, so patterns leaving one side return on the other — the simulation really runs on the chosen surface; the donut just shows it.

Rule

Born / Survive notation — pick a preset or type your own. B3/S23 (Conway) = dead cell with 3 neighbours is born; live cell with 2 or 3 survives.

Bacteria

The selector picks 1, 2, 4 or 6 bacteria types, split into two clans — warm colours (Amber, Rose, Magenta) vs cool (Cyan, Lime, Violet). A neighbour of the same clan counts +1 (types cooperate), the other clan counts −1 — for both birth and survival, so a foe-swamped cell dies and a contested spot stays barren. A newborn takes the majority parent type of the clan that won the cell. One type reduces to classic Life; shrinking the count folds existing cells back into the remaining types without changing clan. With several types, the coloured buttons choose what Pen and Glider place, Random seeds all active types evenly, and the status line splits the population per type in button order.

Topology

  • Torus — both edge pairs wrap.
  • Klein bottle — one seam flips; patterns return mirrored.
  • Möbius / Cylinder — one edge pair is open; cells die at that boundary.

Tools (act on the surface)

  • Orbit — left-drag rotate, right-drag pan, wheel zoom.
  • Pen — left-drag paints the selected type (first cell sets draw vs erase); right-drag still pans.
  • Glider — left-click drops a glider of the selected type where you click.

Run & shape

  • Play / Step — run continuously, or one generation.
  • Random / Clear — seed by density, or empty the grid.
  • Speed, Density, Grid size — sliders; Apply size rebuilds the grid.
  • 2D / 3D view — flat grid (seam behaviour visible) vs torus; Reset view re-centres.

Status line shows generation, population, and flags STABLE or LOOP when the pattern settles or cycles. Click the title bar to collapse this panel. Esc closes this help.
